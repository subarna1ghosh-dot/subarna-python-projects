## Projects Included

### 1. Subarna's AI StudyBuddy (`ai_studybuddy.py`)
A rule-based conversational study assistant built using Python functions, dictionaries, string matching, and `datetime`.
- **Features:** Time-based personalized greetings, case-insensitive keyword matching, real-time clock responses, and continuous chat loop.

### 2. Personal Expense Tracker (`expense_tracker.py`)
A menu-driven command-line finance manager built with Python lists, dictionaries, and exception handling.
- **Features:** Record daily expenses (date, category, description, amount), view itemized history, calculate total spending, and view category-wise summaries.

### 3. Simple Text Editor (`text_editor.py`)
A lightweight desktop notepad application built using Python's built-in `tkinter` GUI library.
- **Features:** Create, open, edit, and save `.txt` files with native OS file dialogs and popup alerts.

### 4. Python Image Slideshow App (`image_slideshow.py`)
An interactive desktop photo slideshow viewer built with `tkinter` and `Pillow (PIL)`.
- **Features:** Select multiple images dynamically via file dialog, automatic image resizing, non-blocking timed slideshow transitions (`root.after`), and start/stop controls.
- **Setup:** Run `pip install pillow` before executing.

### 5. CLI Mini-Games & Utilities
- **Guess the Number (`guess_the_number.py`):** Interactive number-guessing game using `while` loops, input validation, and the `random` module.
- **Countdown Timer (`countdown_timer.py`):** Console countdown utility built with `for` loops, `divmod`, and the `time` module.
